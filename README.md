# React + TypeScript + Vite

## Description

This project is pure React application built with Vite and TypeScript. It is designed as a TASK MANAGEMENT APP for AG Software technical test.

## Features

- React with TypeScript support  
- Vite for fast development and build performance  
- Hot Module Replacement (HMR)  
- ESLint configuration ready for type-checked linting  
- Environment variable management  

## Prerequisites

Make sure you have installed:

- Node.js (recommended LTS version)
- npm or another package manager

And then follow the next steps:

```bash
Verify installation:
node -v
npm -v

1. Clone repository:
git clone <repository-url>
cd <project-folder>

2. Install dependencies:
npm install

3. Configure environment variables
cp .env.example .env
then fill in the required values inside the .env file

4. RUN THE APP
npm run dev
